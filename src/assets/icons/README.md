# Product icons

Generated by `scripts/icons/export.mjs` from the installed `@phosphor-icons/react` (2.1.10, MIT — see `LICENSE`). Contains only the glyphs the product UI renders, at the weights it renders them (regular everywhere; bold where a component passes `weight="bold"`). The shared `Icon` component renders these symbols through `<use>`; a glyph that is not in the sprite (Storybook's icon catalogue, for instance) still renders through the React package. Regenerate with `npm run icons:build`; `npm run icons:check` fails when this folder is stale.
