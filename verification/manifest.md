# Verification evidence — manifest

Curated, tracked captures of the implemented product and design system after the Hi-Fi passes (`docs/design-system/README.md` §16 and §17). Every image here was rendered by a script from the committed source and then read at full resolution; the "Inspection" column is that reading, not an automated result. The complete local capture sets (55 runtime + 37 Storybook images) are regenerated into the ignored `.verification/` directory by the same scripts; only this deliberate subset is tracked, so the repository does not carry redundant or transient output.

- Source state: commit `0994614` (`feat(design-system): fill-width navigation group, tabs-capable segmented control, large button, 2 × 2 method grid`) on `feat/navigation-hifi`; every image below was rendered from that tree.
- Renderer: Playwright's bundled Chromium (headless), `deviceScaleFactor: 2`, mobile emulation with touch. Enlarged text is injected as `html { font-size: 200% }`, the same mechanism the Storybook decorator uses. Runtime captures are full-page, except while a dialog is open, when they are the viewport (a fixed backdrop cannot reach past the viewport, so a full-page capture would show un-scrimmed content that no user sees).
- Regenerate: `npm run build && npx vite preview --port 4173`, then `node scripts/verify/runtime-walkthrough.mjs`; `npm run build-storybook`, then `node scripts/verify/storybook-captures.mjs`. Both scripts fail on console/page errors; the Storybook script also fails when a story's play function throws. `node scripts/verify/nav-radius-compare.mjs` renders the navigation radius variants to `.verification/compare/` (inspection aid, not tracked).
- Superseded evidence: the §16 set (rendered from `6b830ee`: content-hugging navigation with labels on every destination, radio-only segmented control, rows at 320 in the method sheet) was replaced file-for-file by the images below once each replacement had been inspected; the earlier pre-redesign captures were local, ignored files and are gone. Git history holds the §16 images at commit `9af5db9`.
